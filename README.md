# snoring-detection-machine-learning
A machine learning project for detecting snoring sounds from audio recordings using feature extraction and classification algorithms such as SVM, Random Forest, KNN, Logistic Regression, and Decision Tree.
This project detects snoring sounds from audio recordings using machine learning algorithms.
Algorithms Used:
- SVM
- Random Forest
- KNN
- Logistic Regression
- Decision Tree

Dataset:
Kaggle Snoring Dataset

Tools:
- Python
- Google Colab
- Librosa
- Scikit-learn
- NumPy
- Pandas
